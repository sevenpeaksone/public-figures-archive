# Public Figures Archive

주요 인사의 공개 발언, 일정, 활동, 이슈를 **상세 기사/분석/보고서형 콘텐츠**로 정리하는 공개 archive입니다.

이 저장소는 n8n/Hermes 자동화의 운영 저장소가 아닙니다. 수집 규칙, 원천 raw 데이터, 실행 로그, API 설정, credential은 `n8n-mvp` 운영 저장소와 로컬 환경에만 보관합니다.

## Public content layout

- `articles/`: 날짜별 기사형 Markdown
- `reports/`: 공개 가능한 주간/월간/분기/반기 보고서
- `profiles/`: 공개 가능한 인물별 정리 문서
- `stats/`: 공개 가능한 통계/요약 데이터
- `assets/images/`: 공개 가능한 이미지 자료
- `assets/charts/`: 활동 빈도, 주제 분포, 타임라인 등 차트 자료
- `index.md`: GitHub Pages 또는 archive index용 시작 문서

## Content standard

- 단순 요약이 아니라 기사형/분석형/보고서형으로 작성합니다.
- 사실, 발언 인용, 주장/의혹, 해석을 구분합니다.
- 주간/월간/분기/반기 결과물은 보고서 형식을 사용합니다.
- 활동 빈도, 이슈 분포, 기간별 변화가 중요하면 차트를 포함합니다.

## Safety gates

- 반복 실행은 사용자 명시 승인 전까지 비활성입니다.
- live delivery는 사용자 명시 승인 전까지 비활성입니다.
- paid Kakao delivery는 MVP 단계에서 사용하지 않습니다.
- No secrets, raw crawling output, or internal run logs are committed here.

## Visibility

이 repo는 공개 콘텐츠 archive 용도이므로, 소유자가 GitHub에서 repository visibility를 public으로 전환할 수 있습니다.
